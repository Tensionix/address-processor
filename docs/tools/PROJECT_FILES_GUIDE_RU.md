# Карта файлов проекта

[English](PROJECT_FILES_GUIDE_EN.md) · [Справочник](../REFERENCE_RU.md) · [Установка](../INSTALL_RU.md)

Где что лежит. Документ для того, кто будет сопровождать проект: пользователю он
не нужен.

Рабочие папки (`input`, `output`, `logs`, `report`, `release`, `workspace`,
`runtime`, `wheelhouse`) описаны по роли, а не пофайлово — их содержимое
порождается прогонами и пересобирается.

---

## Корень

| Файл | Что это |
| --- | --- |
| `Start.exe` | Скомпилированный запуск окна: открывает `App\AudionAddressProcessor.exe` |
| `address_cli.cmd` | Консольная команда: те же операции без окна; на ней стоит само окно |
| `builder_main.cmd` | Сборка portable-окружения |
| `cleanup_project.cmd` | Очистка наработанных артефактов |
| `pytest.ini` | Настройки тестов |
| `release_manifest.json` | Манифест последней сборки релиза |
| `README.md` | Публичное описание проекта |

CMD-файлы должны оставаться UTF-8 без BOM с переносами CRLF. После правки —
`install\Check-CmdEncoding.cmd`.

## `App` и `Source` — окно

| Путь | Что это |
| --- | --- |
| `Source/` | Исходники окна: Avalonia 12 / .NET 10. `Core/` — запуск команды, манифест, значения полей, журнал, настройки; `Views/` — форма, панели, диалоги; `MainWindow.*.cs` — разделы, рабочая зона, запуск, ОКТМО; `Ps/` — исходник собственного PowerShell программы; `Tools/` — значки и проверка без мыши |
| `Source/config/i18n.json` | Английские пары всех русских текстов окна |
| `App/` | Собранное окно (`AudionAddressProcessor.exe`) и свой PowerShell `AudionPs.exe` для сценариев сборки; собирается `install\Build-App.cmd`, в выпуск едет готовым |

### `services` — сервисный слой

`address_aligner_service.py` — единственный файл. Каждая команда окна ссылается
на функцию отсюда: сервис принимает параметры, вызывает движок, пишет журнал,
отчёт и список артефактов.

### `core` — ядро

| Файл | Что делает |
| --- | --- |
| `jobs.py` | Запуск операций, отмена, прогресс, живая строка хода |
| `operation_model.py` | Правила, по которым собираются параметры запуска: умолчания, условия показа полей, порядок слотов; манифест в виде для окна |
| `window_layout.py` | Чтение `window_layout.yaml` и проверка, что каждая операция стоит в окне |
| `manifest.py` | Разбор `tool_manifest.yaml` |
| `paths.py` | Управляемые папки проекта |
| `config.py` | Чтение настроек |
| `ansi_terminal.py` | Очистка вывода программ от управляющих кодов цвета |
| `cmd_encoding.py` | Проверка кодировок CMD |
| `output_decode.py` | Декодирование вывода подпроцессов |
| `logging_utils.py` | Журналирование |

## `tests` — тесты

| Файл | Что проверяет |
| --- | --- |
| `test_address_aligner_regression.py` | Проходы сопоставления |
| `test_safe_table_join.py` | Перенос колонок по адресу |
| `test_excel_layout.py` | Оформление книг результата |
| `test_console_output.py` | Очистка вывода от кодов цвета, кодировки вывода подпроцессов |
| `test_cli_door.py` | Консольная команда: параметры запуска те же, что у прежнего окна, остановка, Excel и Word |
| `test_window_avalonia.py` | Окно и команда читают одни и те же ключи; английские пары; самопроверка собранного окна |
| `former_window_parameters.json` | Параметры 14 операций, снятые с прежнего окна 11.10.2026: по ним проверяется команда |

Окно проверяется не страницей в браузере, а самим собой: `App\AudionAddressProcessor.exe
--self-check` строит все разделы и сверяет их с манифестом.

`COMPONENTS.json`, отчёт сканирования и манифест пакета. Собираются
инструментом Audion Build Licenses по готовому составу проекта, руками не
правятся.
